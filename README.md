Simple Interest Calculator – Project Details
A Simple Interest Calculator is a beginner-friendly web development project that calculates the interest earned or paid on a principal amount over a specific period at a fixed annual interest rate.
1. Project Overview
- Project Name: Simple Interest Calculator
- Objective: Calculate simple interest and the total amount payable or receivable.
- Technology: HTML, CSS, JavaScript
- Level: Beginner
- Type: Web-based application
2. Formula
The formula for simple interest is:
\[
SI=\frac{P \times R \times T}{100}
\]

Where:
- P = Principal amount (initial money)
- R = Annual rate of interest (percentage)
- T = Time period (in years)
- SI = Simple interest
Total amount:
\[
A=P+SI
\]

3. Example Calculation
Suppose a person invests ₹10,000 at an annual interest rate of 5% for 2 years.
Input / Result	Value
Principal	₹10,000
Annual interest rate	5%
Time period	2 years
Simple interest	₹1,000
Total amount	₹11,000
Calculation:
\[
SI=\frac{10000\times5\times2}{100}=1000
\]

5. Display simple interest.
